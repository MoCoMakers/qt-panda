# Meetings

Bench-meeting plans and their outcomes, one file per meeting topic. Each file starts with a status line. Fill in its result tables and decision lines during or after the meeting, so later weeks can pick up from it.

| file | topic | status |
|---|---|---|
| [`2026-10-streak-followup-plan.md`](2026-10-streak-followup-plan.md) | Horizontal streaks: KIGA decision, gain and line-rate sweeps (incl. 3 Hz), code review fixes, cross-hatch go/no-go | planned |

## Conventions

- Name files `YYYY-MM-<topic>.md`.
- Link the live checklist or report pages at the top. Record results in the file itself, because checkbox ticks on those pages stay in each viewer's own browser.
- Keep decisions and their reasons in the file. Don't keep them only in chat.
